# Taskbar Fortress

작업표시줄 바로 위에서 즐기는 Windows용 작은 탱크 게임입니다. 투명한 영역에는 뒤에 열린 문서나 바탕화면이 보이며, 해당 영역을 클릭하면 뒤의 앱을 사용할 수 있습니다.

## 실행

`bin\Fortress.exe`를 실행합니다. Windows 기본 .NET Framework를 사용하며 별도 패키지를 설치하지 않습니다.

- 탱크 또는 패널을 클릭하여 게임에 키보드 포커스를 줍니다.
- 스페이스바를 누르고 있으면 2초 동안 힘이 충전됩니다. 최대 힘에서 유지됩니다.
- 탱크를 우클릭하면 색상 선택 창이 열립니다. 색상을 고르고 확인하면 몸체와 밝은 부분·그림자 색상이 함께 바뀝니다. 취소하면 기존 색상이 유지됩니다. 선택 중에는 게임이 일시 정지되고 충전은 취소됩니다.
- 선택한 색상은 Windows 사용자 레지스트리 `HKEY_CURRENT_USER\Software\TaskbarFortress`의 `TankColor`에 저장됩니다. 별도 설정 파일이나 관리자 권한이 필요하지 않으며 같은 Windows 사용자 계정에서 다음 실행에도 유지됩니다. 기존 `tank-color.txt`가 있으면 유효한 색상을 이전하고 저장에 성공한 뒤 해당 파일을 삭제합니다.
- 충전 게이지는 탱크 오른쪽에 세로로 표시되며 아래에서 위로 차오릅니다. HIT / SHOTS와 종료 버튼은 게이지 옆의 작은 점수 줄에 표시됩니다.
- 스페이스바를 떼면 고정된 25도 각도로 발사합니다. 같은 착지 거리 기준으로 이전 20도 버전보다 비행 시간이 10% 짧도록 조정되어 있습니다.
- 탱크 중심을 0, 화면 작업 영역의 오른쪽 끝을 100으로 보았을 때 과녁 중심은 10~80 사이에 무작위로 생성됩니다. 최대 충전 시 포탄은 100 위치에 착지할 거리로 발사됩니다.
- 명중하면 HIT가 뜨고 새 위치에 타겟이 생성됩니다.
- 명중한 과녁은 도트 조각으로 터집니다. 2회 연속 명중부터 과녁 옆에 `2 COMBO`, `3 COMBO`가 표시되며 빗나가면 콤보가 초기화됩니다.
- 빗나가면 MISS가 뜨며 같은 타겟을 다시 노릴 수 있습니다.
- HIT / MISS 결과는 과녁 오른쪽 옆에 표시됩니다. 오른쪽 공간이 부족하면 왼쪽 옆에 표시됩니다.
- 다른 앱을 클릭하면 충전을 취소하고 그 앱에 키보드 입력을 넘깁니다.
- 게임에 포커스가 있을 때 Esc 또는 패널의 × 버튼으로 종료합니다.

## 빌드

프로젝트 폴더에서 `powershell -ExecutionPolicy Bypass -File .\build.ps1`을 실행합니다.

## 첫 버전의 범위

기본 모니터의 작업 영역 아래쪽에 배치됩니다. 아래쪽에 고정된 작업표시줄을 기준으로 설계했으며 작업표시줄 자동 숨김 또는 세로 배치에서는 작업 영역 아래쪽에 표시됩니다. 전체 화면 전용 앱에서는 표시가 보장되지 않습니다. 게임 창은 다른 일반 창 위에 유지됩니다. 화면 크기나 작업 영역이 변경되면 현재 발사를 취소하고 배치를 다시 계산합니다.
